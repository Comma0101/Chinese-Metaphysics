# 知几 · 社媒发帖能力与运营手册

> 问题:Claude(我)能不能替你自动往这些平台发帖?
> **一句话结论:小红书(你的主战场)——不能,而且不该碰自动化,现在正撞在封号潮上。我的角色到「起草」为止,你人工发。西方平台可以真自动化,但那不是你的主要受众。**

## 三条通道(按"自动化是否安全"分)

| 通道 | 平台 | 谁来发 |
|---|---|---|
| **A · 可端到端自动**(我起草+我发布) | Threads(最佳)、X、Facebook Page | Agent 通过官方 API 发 |
| **B · 我起草 + 人工/审核后发** | Instagram、TikTok(草稿模式)、YouTube | Agent 备好,人点发布 |
| **C · 只能人工,永不自动** | **小红书**、Bilibili | 人手发,我只起草 |

**你的受众在 C 档(小红书)。** 所以残酷的现实:对你的**主渠道**,自动发帖既不可能也不该做——自动化的杠杆对你其实很小,只有以后做西方平台二次分发时才用得上。

## 平台矩阵

| 平台 | 官方发帖 API | 能自动化? | 有现成工具/MCP | 新号封号风险 | 起步要什么 |
|---|---|---|---|---|---|
| **小红书** | **无**(公开平台只做广告/蒲公英数据/私信,发布只能扫码在 App 内发) | 只有非官方浏览器脚本/逆向,脆弱 | 只有社区浏览器自动化 MCP(封号风险) | **高→极高**。2025.9 起常态化封号潮,专打矩阵/AI批量/"营销机器" | 一部手机、一个真人、发帖前**养号 ~7 天** |
| **Threads** | 有(官方,免费) | 是,完全 | Ayrshare/Postiz 等 | 低 | Meta app + OAuth;250 帖/24h。**摩擦最低的全自动面** |
| **X/Twitter** | 有(API v2) | 是 | 多个 X MCP | 低 | **2026.2.6 起按量付费:约 $0.015/帖,带链接 $0.20/帖**,新号无免费额度 |
| **Instagram** | 有(Graph API 两步) | 是 | Ayrshare/Buffer 等 | 中 | 商业号+FB Page+应用审核(2–4 周,常首次被拒);25 帖/24h |
| **Facebook Page** | 有 | 是 | 主流调度器都支持 | 低 | Page token + 应用审核 + 企业验证 |
| **YouTube** | 有(Data API) | 是 | Ayrshare/Postiz | 低,但**陷阱**:未过审项目上传强制私有 | GCP + OAuth,先过合规审核否则视频只能私有 |
| **TikTok** | 有(Content Posting) | 是 | Mixpost/Ayrshare | 中 | 未过审强制私有+5用户/24h;**草稿模式无需过审**(安全打法) |
| **Bilibili** | **无**通用发布 API | 只有社区逆向(biliup) | 社区 CLI,无主流 | 中高 | cookie + 社区工具,灰色 |

> **重点:所有合规的托管发帖工具/MCP(Ayrshare、Postiz、Mixpost、Buffer、Hootsuite…)全都不支持小红书。** 这不是疏漏——是因为根本没有厂商可用的小红书发布 API。

## 小红书:唯一安全的运营方式(现在就要照做)

1. **当成纯手动账号运营。** 我只交付「可直接粘贴」的内容:标题、正文、话题标签、封面脑图、发布时间建议。**绝不**给品牌号接任何自动发布器/浏览器 MCP/逆向客户端。
2. **发帖前先养号 ~7 天**:真实浏览/点赞/评论/关注同领域内容,再发第一条。第一周**别绑微信/实名/推广签名**。← **这是发内容批次之前的第一步。**
3. **单机单卡单号**,住宅网络,真人作息时间发。
4. **节奏**:起步每天 1 条或隔天 1 条,高质量,**绝不跨号同质内容**,远离"矩阵"footprint。
5. **周边可以自动、发帖动作不自动**:我可以帮你排提醒、备素材包、从你手动导出的数据里做表现分析、起草回复给你手动发。账号在平台上的行为保持 100% 人工。

## 关键不确定项(用前复核)
- X 价格来自 2026 第三方追踪,发前在 X 开发者后台核一遍。
- YouTube 上传配额单价(1600→可能~100)各源不一,用官方 Quota Calculator 确认。
- 小红书"某 MCP 一年没封号/50帖每天"是单一维护者传闻,**非政策,别信**。
- 小红书执法 2025–2026 在收紧,今天的自动化容忍度可能随时消失。

## 我能替你做 / 不能做
- ✅ 起草全部内容、封面脑图、时间建议、回复草稿、表现分析、素材打包
- ✅ 以后帮你把 Threads/X/FB 的**二次分发**做成真自动化
- ❌ 替你在小红书上发帖/评论/点赞(只读工具 + 品牌安全,不做)
