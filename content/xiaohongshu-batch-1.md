## ⚠️ 运营红线(每条发布前必过)

- **删光玄学词**:算命、算卦、运势、转运、改运、风水、旺财、保佑、化解、破太岁、以及任何"预测具体结果"。用 **决策 / 复盘 / 自我认知 / 结构 / 时机 / 模式 / 理性** 替代。

## Pillar 1 — 决策节点叙事案例(打头 · 调研背书最强)

格式:**素人心路历程 → 一个结构化框架如何厘清选择**。定位为决策/自我认知,**不预测、不承诺**。这是调研里唯一既有效又低风险的 thesis format。

### 1A · 身份不稳定:该攻还是该守
- **钩子:** 身份没定的那两年,我一直在纠结该冒险还是该猫着。后来帮我理清的,不是"算",是一个看"我这几年适合扩张还是收缩"的框架。
- **骨架:** 具体处境(签证/OPT 焦虑)→ 我原来怎么反复 → 框架怎么把问题从"吉凶"重构成"当前阶段的风险姿态"→ 我最后怎么选、为什么不后悔 → CTA。
- **红线:** 不碰"能不能拿到身份"这类结果预测。

### 1B · 两个 offer 怎么选
- **钩子:** 两个 offer,别问哪个"旺你"。真正该问的是:这三年的你,适合稳,还是适合搏。
- **骨架:** 把选择从玄学吉凶重构成风险姿态 → 一个稳/搏错配的真实故事 → CTA。

### 1C · 总开新坑不 ship(戳独立开发者/创作者)
- **钩子:** 我总开新项目却从不真正 ship。后来发现这不是自律问题——是我把"开始"当成了逃避"分发"的方式。
- **骨架:** 讲这个 recurring pattern 的结构成因 → 框架怎么让我看见自己在哪个环节习惯性逃 → CTA。

### 1D · 代际压力:父母在国内,我在海外
- **钩子:** 催婚、催回国、催稳定——我花了很久才把"愧疚"和"我真正想要的"分开。
- **骨架:** 处境 → 情绪与选择纠缠 → 框架怎么帮我看清边界 → CTA。

## Pillar 2 — 反神棍 / 可信度(调研背书:低监管风险 + 真差异化)

市场充斥巴纳姆通用话术、假素人、割韭菜,用户(尤其高知)越来越犬儒。**替他们说出对神棍的不屑,就是你的位置。**

### 2A · 为什么我不给你算桃花运、也不算发财
- **钩子:** 我不给你算桃花运,不给你算发财,也不给你转运。这条讲为什么。
- **骨架:** 立场:这是决策梳理,不是预测 → 那套承诺为什么是收割话术 → "我只做:结构、时机、模式、复盘" → 礼貌劝退错的人,留下对的人。

### 2B · 给你"确定未来"的,先别信
- **钩子:** 但凡有人给你一个确定的未来,先警惕。负责任的判断给的是概率和边界,不是保证。
- **骨架:** 拆"确定性承诺"的话术机制 → 对比"负责任的判断长什么样" → CTA。

### 2C · DeepSeek 能算命,那我这样的还有什么用?
- **钩子:** AI 几秒给你一篇八字报告,读着还挺准。这条讲:它准在哪、又缺了什么。
- **骨架:** 承认 AI 通用话术的"准"来自巴纳姆效应 → 真正缺的是校准、追问、和对你具体处境的判断 → CTA。
- **为什么有效:** 蹭 DeepSeek 算命热度,又把自己和廉价通用话术划清界限。

## Pillar 3 — 复盘/校准案例(回顾式,非预测)

> ⚠️ 这是 v1「验盘 demo」的安全替代。**不做**"预测陌生人未来/具体结果"的公开盲测。改做**回顾式、经本人同意**的案例,框架是模式识别与自我认知。真正的盲测放 /free 自有站做。

### 3A · 一个框架"说中了他过去的什么"(经同意)
- **钩子:** 一位读者让我公开他的复盘。有两点他说很准,一点我读偏了——偏的那点我告诉你为什么。
- **骨架:** 回顾式描述几个**已发生**的模式(不是预测)→ 本人反馈 → **重点讲我读偏的那点**(信息不足/我的偏差)→ "这就是为什么我坚持先复盘校准" → CTA。
- **红线:** 全程用过去时/模式语言,不碰未来预测。

### 3B · 同一天出生 ≠ 同一命
- **钩子:** 两个同一天出生的人,走向可以完全不同。这条讲差别从哪来。
- **骨架:** 拆"生辰决定一切"的误解 → 讲时辰/地点/阶段的方法差异 → 落到"所以我需要你的出生城市和时间" → CTA。

## 运营与指标

- **节奏:** 起步每天 1 条或隔天 1 条(远低于"矩阵"footprint),高质量,绝不跨号同质。
- **封面:** 克制大字标题、留白;不用神秘花哨元素。
- **只看两个指标:** 内容→盲测留资率、盲测→付费转化率(别看粉丝数)。
- **量的瓶颈:** 盲测火了会做不过来 → **设名额**(如本周 10 个),也回答"是产品还是咨询"的规模化问题。
